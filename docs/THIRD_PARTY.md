# Third-party software

The LocaLeaf release contains the following software besides its own code. Each part keeps its own license.

| Component | What it is used for | License | Source |
|---|---|---|---|
| texlyre-busytex 1.4.1 | The TeX engine: TeX Live programs (pdfTeX, XeTeX, LuaTeX, BibTeX, makeindex, …) and Biber compiled to WebAssembly, with TeX Live's "recommended" collection | AGPL-3.0 (build); the bundled programs keep their licenses, below | [github.com/TeXlyre/texlyre-busytex](https://github.com/TeXlyre/texlyre-busytex) |
| TeX Live 2026 (programs and the "recommended" collection) | Inside busytex | Various free licenses, mostly the LaTeX Project Public License, GPL and public domain; each package states its own | [tug.org/texlive](https://tug.org/texlive/), [CTAN](https://ctan.org/) |
| Biber | Inside busytex | Artistic License 2.0 | [github.com/plk/biber](https://github.com/plk/biber) |
| fontconfig, expat | Inside busytex (font lookup for XeTeX) | MIT-style | [fontconfig](https://www.freedesktop.org/wiki/Software/fontconfig/), [libexpat](https://github.com/libexpat/libexpat) |
| Emscripten runtime | Inside busytex (the WebAssembly glue code) | MIT / University of Illinois NCSA | [emscripten.org](https://emscripten.org/) |
| xz-decompress 0.2.3 (with xzwasm, walloc and xz-embedded inside) | Unpacking TeX Live package archives from CTAN | MIT (xz-decompress, xzwasm, walloc); xz-embedded: public domain. The notices are kept in `engine-worker.js` | [xz-decompress](https://github.com/httptoolkit/xz-decompress), [xzwasm](https://github.com/SteveSanderson/xzwasm), [walloc](https://github.com/wingo/walloc), [xz-embedded](https://tukaani.org/xz/embedded.html) |

**Generated data:** `font-index.json` and `texlive-files.json.gz` list file and font names from TeX Live
2026. They are generated by `scripts/build-font-index.mjs` and `scripts/build-texlive-index.mjs`.

**Downloaded at runtime, not shipped:** packages and fonts from TeXlyre's TeX Live file server and from a
CTAN mirror, each under its own license (see the README's
[Privacy and network](../README.md#privacy-and-network)).

**Overleaf** is not included. LocaLeaf talks to it the way the Overleaf editor does; parts of its protocol
were studied in Overleaf's source ([github.com/overleaf/overleaf](https://github.com/overleaf/overleaf),
AGPL-3.0).

LocaLeaf itself is licensed under the [AGPL-3.0](../LICENSE). Its source code is at
[github.com/Delici0u-s/locaLeaf](https://github.com/Delici0u-s/locaLeaf).
